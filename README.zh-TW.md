## 為什麼做 DoDodo

計畫一天做三件事，結果一件也沒做完。很多時候缺的不是專注力，而是一個「此刻就能感受到」的理由。薪水離得太遠，而「今天做完獎勵 50 元」馬上就有效。

DoDodo 給每個任務一個即時的回報。你完成的每個任務都會讓一位冒險者成長，他有自己的小小人生：新的天賦、偶然的際遇、一段持續一個月的故事。錯過任務時，你會看到冒險者錯過的機遇。已經獲得的成長永遠不會失去。

## 怎麼用

1. **領任務**：寫下要做的事，按 Enter。DoDodo 會自動判斷屬性（力量、智慧、魅力、技藝），截止時間預設為你的下班時間。
2. **開始**：任務進行時，DoDodo 會悄悄記下你在哪個網站。跑步、買菜這類線下任務不需要記錄。
3. **完成**：點一下就好。只有專注時間太短時，DoDodo 才會多問一句。
4. **回家**：下班後公會結算這一天：經驗、升級、人生事件，以及錯過的機遇。

## 功能

- **一行建立任務**：不用填表。每天最多三個，讓計畫保持誠實。
- **真實的專注，而不是打勾**：成長來自你真正花在工作上的時間。
- **值得每天回來看的故事**：第一章大約持續 30 天，全部手寫，沒有 AI 拼湊的內容。
- **看得見的改變**：7 天專注圖表、準時完成率，以及你最容易分心的時段。
- **公平設計**：不能花錢買經驗，沒有捷徑，也不會因為中斷連續紀錄而羞辱你。

## 隱私優先

- 所有資料都儲存在瀏覽器的本機資料庫裡。DoDodo 從不連網。
- 只在任務進行時記錄目前分頁的**網域**，從不記錄完整網址、頁面標題或頁面內容。
- 不需要帳號，沒有統計，沒有廣告。在設定裡一鍵匯出或刪除全部資料。
- 完整政策: [隱私權政策（英文）](https://github.com/hannnnnnnny/dodo-privacy/blob/main/PRIVACY.md)
