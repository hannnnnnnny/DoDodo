## 왜 DoDodo인가

하루에 세 가지를 계획하고 하나도 끝내지 못한 적이 있나요? 부족한 건 집중력이 아니라 "지금 당장" 느껴지는 이유인 경우가 많습니다. 월급은 너무 멀지만, "오늘 끝내면 5천 원"은 바로 효과가 있죠.

DoDodo는 모든 할 일에 즉각적인 보상을 줍니다. 퀘스트를 끝낼 때마다 모험가가 성장하고, 자신만의 작은 삶을 살아갑니다. 새로운 재능, 우연한 만남, 한 달에 걸쳐 펼쳐지는 이야기. 퀘스트를 놓치면 모험가가 놓친 기회를 보게 됩니다. 이미 얻은 성장은 절대 사라지지 않습니다.

## 사용 방법

1. **퀘스트 받기**: 할 일을 입력하고 Enter를 누르세요. 속성(힘, 지혜, 매력, 기술)은 자동으로 정해지고, 마감은 퇴근 시간으로 설정됩니다.
2. **시작**: 퀘스트가 진행되는 동안 DoDodo가 어떤 사이트에 있는지 조용히 기록합니다. 달리기, 장보기 같은 오프라인 퀘스트는 기록이 필요 없습니다.
3. **완료**: 한 번만 누르면 끝. 집중 시간이 너무 짧을 때만 한 번 더 묻습니다.
4. **귀환**: 퇴근 후 길드가 하루를 정산합니다. 경험치, 레벨업, 인생 이벤트, 그리고 놓친 기회.

## 기능

- **한 줄 퀘스트**: 양식이 없습니다. 하루 최대 세 개라서 계획이 솔직해집니다.
- **체크박스가 아닌 진짜 집중**: 성장은 실제로 일에 쓴 시간에서 나옵니다.
- **다시 보고 싶은 이야기**: 1장은 약 30일에 걸쳐 펼쳐지며, 모두 직접 쓴 글입니다. AI로 채운 내용은 없습니다.
- **변화의 증거**: 7일 집중 차트, 기한 내 완료율, 가장 산만해지는 시간대.
- **공정한 설계**: 경험치 구매 없음, 지름길 없음, 연속 기록이 끊겨도 탓하지 않습니다.

## 개인정보 보호 우선

- 모든 데이터는 브라우저의 로컬 데이터베이스에 저장됩니다. DoDodo는 인터넷에 연결하지 않습니다.
- 퀘스트가 진행 중일 때 활성 탭의 **도메인**만 기록합니다. 전체 URL, 페이지 제목, 페이지 내용은 기록하지 않습니다.
- 계정 불필요, 분석 없음, 광고 없음. 설정에서 한 번에 데이터를 내보내거나 삭제할 수 있습니다.
- 전체 정책: [개인정보처리방침 (영어)](https://github.com/hannnnnnnny/dodo-privacy/blob/main/PRIVACY.md)
