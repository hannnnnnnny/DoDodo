## なぜ DoDodo なのか

一日に三つ予定して、一つも終わらない。足りないのは集中力ではなく、*いま* 実感できる理由であることが多いものです。来月の締め切りは遠い。でも、今夜あなたを必要としている誰かは、遠くない。

DoDodo では、終えたクエストのひとつひとつが恩寵になり、Hollowmere の生存者に届きます。静かな町ですが、日が暮れると何かが戸口にやってくる。あなたが代わりに戦うことはできません。できるのは、自分の仕事を終わらせ、井戸に何を落とすか選び、翌朝に届く手紙を読むことです。

## 使い方

1. **クエストを受ける**：やることを入力して Enter。1 日 3 つまで、締め切りは終業時刻です。
2. **仕事をする**：クエスト中は、どのサイトにいるかを DoDodo が静かに記録します。ランニングや買い物のようなオフラインのクエストは記録不要です。
3. **恩寵を得る**：ワンタップで完了。期限内なら恩寵 2、遅れたら 1。
4. **助けを送る**：恩寵をお守りや建物に換えて、恩寵の井戸に落とします。夕暮れ、生存者はそれを汲み上げ、空に礼を言って、夜を迎えます。

## 機能

- **見届ける夜**：毎晩、小屋を舞台にした短いアニメーションが流れます。8 種類の怪異は、それぞれ違うやり方で入り込んでくる。数字は常に表示されます。今夜の脅威、あなたの防御、そしてその内訳。
- **神の選択**：高みからは、生存者には見えない前兆が見えます。19 種のお守りと 10 種の建物から選びましょう。正しい夜に正しい贈り物を届けることが、生き延びる鍵です。
- **嘘をつく掟**：期限内にクエストを終えると、町の規則が少しずつ戻ってきます。中には偽物もあり、信じる一行を間違えれば代償を払うことになります。
- **毎朝届く手紙**：生存者は、助けてくれる誰かに宛てて手紙を書きます。それがあなただとは知らないまま。
- **チェックではなく、本物の集中**：7 日間の集中グラフ、期限内達成率、いちばん気が散る時間帯。
- **公平な設計**：恩寵の課金購入なし、近道なし、連続記録が途切れても責めません。生き延びる方法は、仕事を終わらせることだけ。

## プライバシー重視

- すべてのデータはブラウザのローカルデータベースに保存されます。DoDodo はインターネットに接続しません。
- 記録するのはクエスト中のアクティブなタブの**ドメイン**だけ。完全な URL、ページタイトル、ページ内容は記録しません。
- アカウント不要、解析なし、広告なし。データはすべて設定からエクスポート・削除できます。
- 詳しくは: [プライバシーポリシー（英語）](https://github.com/hannnnnnnny/dodo-privacy/blob/main/PRIVACY.md)
